# Рейтинг-портал по финансовым продуктам

## Обзор проекта

Это проект по созданию оригинального сайта-рейтинга и сравнительного каталога финансовых продуктов и сервисов: виртуальные карты, дебетовые карты, кредитные карты, вклады, SIM-карты, оплата сервисов.

Основная идея проекта:
- помогать пользователю сравнивать выгодные предложения;
- работать через партнерские ссылки и реферальные офферы;
- минимизировать ручной труд за счет автоматизации обновления данных;
- создавать масштабируемый проект, который можно развивать по категориям.

## Принципы проекта

- Не копия чужого сайта, а самостоятельный продукт с похожей бизнес-логикой.
- Ориентация на полезность пользователю, а не только на внешний вид.
- Отдельная работа над партнерскими условиями, данными и автоматизацией.
- Разработка по принципу MVP: сначала узкая, рабочая версия, потом рост.

## Ключевые бизнес-цели

1. Сформировать полезный рейтинг-портал для финансовых продуктов.
2. Подключить партнерские программы и получать доход от рефералов.
3. Автоматизировать обновление данных, условий и ссылок.
4. Поднять проект до уровня масштабируемого digital business.

## Основные категории

- виртуальные карты;
- дебетовые карты;
- кредитные карты;
- вклады;
- SIM-карты;
- оплата сервисов.

## MVP

План запуска:
- 1–2 MVP категории: например, виртуальные карты и вклады;
- рабочие страницы категорий;
- база данных офферов;
- партнерские ссылки и базовая аналитика;
- базовый процесс обновления данных;
- основной SEO-контент.

## Каталог сервисов

- [services.html](services.html) — подбор карты по зарубежному сервису.
- [services.js](services.js) — поиск, категории и переход к подходящей карте.

Каталог сервисов собран по страницам `plativputi.com/cards` и `yello-card.com/#cards`. Статусы `listed`, `available` и `unavailable` являются предварительными отметками источников и должны перепроверяться перед публикацией.
