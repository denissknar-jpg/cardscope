# Data sources

`card-comparison.json` is the normalized catalog created from `Rate.xlsx`.

The original workbook columns are preserved as:

- `rank` — position in the source table
- `name` — service name
- `website` — official site
- `issue` — card issue price
- `service` — monthly service fee
- `topup` — top-up fee
- `validity` — validity period
- `currencies` — supported currencies
- `wallets` — Apple Pay / Google Pay support
- `binCountry` — bank BIN country or region
- `rating` — source rating
- `reviews` — review count
- `features` — source feature note
- `verification` — verification status

The source records are not treated as verified financial recommendations. Each offer must be checked before publication and before adding an affiliate link.
