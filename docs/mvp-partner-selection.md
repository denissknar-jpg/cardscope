# MVP selection: партнеры по виртуальным картам

## 1. Цель

Сформировать первичный список партнёров по виртуальным картам, оценить их пригодность для запуска проекта и выбрать оптимальные кандидаты для MVP.

## 2. База для отбора

Критерии отбора:
- прозрачность партнерских правил;
- понятная система выплат;
- техническая совместимость;
- наличие стабильной ссылки или API;
- допустимые каналы трафика;
- низкий риск репутационных и юридических проблем;
- возможность быстрого включения в каталог.

## 4. Критерии ранжирования

Каждый партнёр оценивается по шкале 1–5:

- прозрачность условий;
- стабильность выплат;
- техническая совместимость;
- удобство автоматизации;
- репутационный риск;
- сложность рекламных ограничений.

## 5. Кандидаты в MVP

На данный момент лучшие кандидаты для стартового запуска:

1. BankLink Flex
   - низкий риск;
   - API есть;
   - прозрачные условия;
   - легко интегрировать в каталог.

2. FastCash Card
   - простой оффер;
   - понятная модель выплат;
   - хороший кандидат для базового теста.

3. VisaLite Digital
   - простая модель работы;
   - низкий риск;
   - хороший вариант для проверки логики сравнения и каталога.

## 6. Почему эти кандидаты лучше остальных

Потому что они обладают тремя ключевыми признаками:
- понятная структура оффера;
- приемлемые условия для запуска и тестирования;
- хорошая вероятность быстрого и понятного включения в платформу без сложной интеграции.

## 7. Что делаем дальше

Нужно выполнить 4 шага:

1. уточнить реальные условия по выбранным 3 партнёрам;
2. определить точный набор полей для карточки продукта;
3. сформировать структуру базы данных для оффера;
4. подготовить первый пакет данных для MVP в формате JSON/CSV.

## 8. Результат этапа

На выходе получаем:
- 3–5 партнёров в базе;
- понятную структуру оффера;
- лучшее соответствие требованиям MVP;
- базу для автоматического обновления в будущем.
